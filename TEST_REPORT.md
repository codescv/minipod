## 5. Security Verification

- **Safe `MediaSession` Command & Seek Clamping**: `MediaSession.Callback.onCustomCommand` and `onMediaButtonEvent` strictly whitelist `dev.minipod.app.action.SEEK_BACK` (`-10,000 ms`), `dev.minipod.app.action.SEEK_FORWARD` (`+30,000 ms`), and `KEYCODE_MEDIA_REWIND` / `FAST_FORWARD` / `SKIP_BACKWARD` / `SKIP_FORWARD` (`repeatCount == 0` single-shot guard against long-press seek storms), returning `RESULT_ERROR_NOT_SUPPORTED` for unknown custom actions. `LockScreenControls.clampSeekTargetMs` and `LockScreenSessionPlayer.seekTo` clamp all external controller/seekbar positions safely into `[0, durationMs]` with `Long` overflow saturation guards and non-mutating command availability checks.
- **Zero Untrusted DOM Sinks**: Verified `0` uses of `innerHTML`, `dangerouslySetInnerHTML`, `outerHTML`, `document.write`, or `eval` across UI and host packages; all localized notification/lock-screen labels (`en`, `zh-CN`, `ja`) come from static Android string resources (`R.string.minipod_lock_screen_*`).
- **Zero Hardcoded Secrets or PII**: Verified `0` hardcoded user emails, OAuth tokens, API keys, or credentials across source, tests, and build scripts.
